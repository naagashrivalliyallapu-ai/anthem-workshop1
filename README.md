# Anthem Workshop

## Project Title
Jana Gana Mana - National Anthem of India

## About the Project
This project was created as part of a Git and GitHub practice workshop. It demonstrates how multiple users can collaborate on a project using Git and GitHub.

## Technologies Used
- Git
- GitHub
- HTML
- CSS
- Python
- Flask

## Project Features
- Displays the Indian National Anthem.
- Provides a simple HTML web page.
- Demonstrates collaboration between multiple users.
- Includes Git operations such as branching, merging, pushing, pulling, and conflict resolution.
